# Милый моему сердцу Людмиловск

Игра от первого лица. Стек: Unreal Engine 5 + Blender.

## Структура

- `blender/scripts/` — скрипты, которые собирают сцены в Blender (запускаются headless).
- `blender/` — собранные `.blend` файлы.
- `blender/export/` — экспорт для Unreal (`.glb`).
- `textures/` — текстуры: экран ОС героя, `podyezd/` — стены, плитка, потолок (Nano Banana 2.1 через fal).
- `audio/` — звуки (гул вентиляции).
- `tools/` — генераторы текстур (`gen_textures_fal.py`, нужен `FAL_API_KEY`) и звука (`gen_vent_hum.py`).
- `renders/` — контрольные рендеры.
- `unreal/Lyudmilovsk/` — проект Unreal Engine 5.8 (шаблон First Person).
- `unreal/scripts/` — скрипты, которые собирают уровни Unreal из `.glb`.

## Сцена 1: Коридор-пирамида

Длинный коридор с высокими наклонными стенами, сходящимися к потолку.
Вдоль левой стены бегущая дорожка без ограждений, вдоль правой длинный стол с самыми разными
местами: CRT с таблицей, старый телевизор с 16-битной приставкой, телевизор с PS2, игровой
сетап с двумя мониторами, VR-угол, бежевый ПК девяностых, ZX-подобный компьютер, ноутбук,
iMac G3, современная консоль. Системники стоят под столом, провода свисают к удлинителям.
Кресла все разные: табуретка, венский стул, складной, офисное, игровое, Herman Miller.
На столе и на полу стаканы от колы, бумажные пакеты, коробки от бургеров, картошка.
Последнее место за столом занимает включённый компьютер героя с простой ОС. Игрок просыпается от первого
лица в темноте, глядя на этот экран. Выхода пока нет.

Коридор оформлен как советский подъезд: стены снизу в зелёной масляной краске, сверху побелка,
на полу метлахская плитка, тёплые лампы-шары на длинных шнурах, чугунные батареи, почтовые ящики
и электрощиток. Вдоль левой стены над дорожкой висит тёплая гирлянда, под высоким потолком идёт
оцинкованный воздуховод с решётками и вентиляторами, от которых слышен гул.

Пересобрать сцену:

```bash
/Applications/Blender.app/Contents/MacOS/Blender -b -P blender/scripts/build_scene01_corridor.py
```

## Unreal Engine

Проект: `unreal/Lyudmilovsk/Lyudmilovsk.uproject` (UE 5.8, Blueprint и модуль C++ `Source/Lyudmilovsk`).
После клонирования модуль нужно один раз собрать (нужен Xcode):

```bash
"/Users/Shared/Epic Games/UE_5.8/Engine/Build/BatchFiles/Mac/Build.sh" LyudmilovskEditor Mac Development -Project="$PWD/unreal/Lyudmilovsk/Lyudmilovsk.uproject"
```

В модуле есть `AConveyorBelt`: бегущая дорожка, которая разгоняется, когда на неё встаёшь,
и плавно останавливается, когда сходишь.
Стартовый уровень: `/Game/Scene01/Lvl_Scene01`, игрок появляется у стула героя
лицом к включённому экрану. Управление шаблонное: WASD, мышь, пробел.

Пересобрать уровень из `.glb` (редактор должен быть закрыт):

```bash
unreal/scripts/build_scene01.sh
```

### Unreal MCP

В проекте включён встроенный плагин Epic «Unreal MCP» (ModelContextProtocol)
и все тулсеты. Сервер стартует вместе с редактором: `http://localhost:8000/mcp`.
`.mcp.json` в корне репозитория подключает его к Claude Code автоматически.

## Git и LFS

Бинарные файлы (`.uasset`, `.umap`, `.blend`, `.glb`, картинки, звук, видео)
хранятся через Git LFS, правила в `.gitattributes`. `.gitignore` и LFS не мешают
друг другу: `.gitignore` решает, попадёт ли файл в репозиторий вообще, а
`.gitattributes` решает, как он хранится. Перед клонированием нужен `git lfs install`.
