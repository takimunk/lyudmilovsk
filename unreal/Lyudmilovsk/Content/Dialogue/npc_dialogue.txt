# [Id]      the mesh name without SK_ (SK_Streamer -> Streamer); the owner is Owner. Its keys use the id in lowercase.
# first =   the first conversation: line keys in order, without the 'line.' prefix (there may be several first lines)
# again =   every later conversation takes the next 'again' line, round and round
# sun.<state> = now and then (every third later talk) a line about what the sun is doing now: day, low (sunrise or
#             sunset), night, cloudy. The motif: docs/story/motifs.md. Quiet hints, not every character has them.
# Keys are separated by ' | '; a key whose speaker is 'hero' is said by the player.
# quest.<quest>.<stage>[,<stage>...] = what they say while that quest (Content/UI/quests.json) is on one of these stages,
#             instead of everything above; 'done' is the stage of a finished quest. A quest this very talk begins
#             (start_on talk) counts as on its first stage. quest.<quest>.<stage>.again = every later talk there
#             (without it the same lines again; a 'done' talk without it is said once, then the everyday talks go on).
#             docs/quests.md.
