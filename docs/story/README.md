# Сценарий и лор «Милый моему сердцу Людмиловск»

Единый живой источник правды по истории, концепции и лору игры. Сюда собираются все идеи Димы.

## Правила ведения

- **Канон** — только то, что сказал Дима. Записывается близко к его словам, с датой.
- **Предложения Claude** помечаются блоком `> 💡 Предложение (не канон)`. Канон они становятся, только когда Дима их одобрит.
- Сырые идеи без места сначала падают в [inbox.md](inbox.md), потом разносятся по файлам.
- Внутриигровой текст (реплики, надписи) потом делается по скиллу локализации: ru/en/ja.
