# Resident generator: sources and licences

The residents are built from MakeHuman data through MPFB2 (see `blender/humans/SOURCES.md` for MPFB2 itself, the
base mesh, targets and rigs: CC0). Assets come from the MakeHuman packs on the Mac or, where those can't be downloaded,
from the npm package [`makehuman-data@0.0.2`](https://www.npmjs.com/package/makehuman-data) (sha512 pinned in
`tools/residents/mhdata_assets.py`, which converts them back to MPFB asset folders). Only CC0 and CC-BY assets are used.
